## Qué librería elegimos?

Elegimos la librería de JavaScript Tom Select.


## Qué hace?

Tom Select es una librería liviana e independiente (sin dependencias como jQuery) que transforma los elementos `<select>` y campos `<input>` nativos de HTML en selectores desplegables avanzados, dinámicos y personalizables.


## Cómo la implementamos?

Hicimos una simulación de carrito de compra al estilo 'pedidosYA' para poder mostrar las diferentes formas en las que la librería permite visualizar los elementos select. Cada select es una categoría de elementos de supermercado y lo diversificamos mediante los plugins que Tom Select tiene disponible
